ANANYA MEHENDI DESIGNS — FREE STATIC VERSION

Files:
- index.html
- style.css
- script.js

How to publish for free:
1. Create a GitHub account.
2. Create a new public repository named ananya-mehendi.
3. Upload these 3 files.
4. Open Settings -> Pages.
5. Under Build and deployment choose "Deploy from a branch".
6. Select main and / (root), then Save.
7. GitHub will give you a public website URL.

Notes:
- Replace the 4 gallery image URLs in index.html with your own photos when you have them.
- The booking form opens WhatsApp; it does not require a paid database/backend.
- Contact details are based on the information supplied in the chat.
